78:WHERE tenant_id = ? AND conversation_id = ? AND direction = 'inbound' AND content_text IS NOT NULL

结论:

- intent = 最近 20 条 inbound。

- outbound 明确排除,客服话术不会进入 intent context。

## 插件自动刷新

实现:

- popup 启动时继续传 `reloadAfterStart: true`。
- background 收到 `START_PLATFORM` 后读取 `platformDefinitions.detect_hosts/pages.detect_hosts`。
- 只刷新 URL 命中目标平台 detect_hosts 的 tab。
- 若匹配 tab 已刷新,不再向旧 content script 发 `START_COLLECTOR`,避免刷新前后重复启动。
- 若未刷新,保持原逻辑向当前 tab 发送 `START_COLLECTOR`。

Node stub 验证:

```json
{
  "reload": [7, 8],
  "sendMessage": [[11, "START_COLLECTOR"]],
  "query": 1
}
```

结论:

- 当前匹配的抖音页会刷新。
- 当前页不匹配时,只查询并刷新已识别的抖音目标页。
- 无关 tab 未刷新。
- 未启用自动刷新时仍走旧的 `START_COLLECTOR` 消息。
