## 5. 下一步执行顺序(新机)
1. 接手仓库:`git fetch origin && git checkout w20-account-governance`(或加 worktree)。`npm install`(根 workspace,装 server+admin+plugin 依赖)。
2. 配 `server/.env`:复制 `server/.env.example`,填 `DB_HOST/DB_PORT/DB_USER/DB_PASSWORD/DB_NAME=chatsift`、`JWT_SECRET`(与插件/已有 token 一致则沿用)、`PORT=3100`。
3. dev 库:本机 MySQL 建库 `chatsift`,**按序** apply `server/sql/00_reused_tables.sql → v1-schema.sql → 02_w19_tenant_asset.sql → 03_w20_account_governance.sql`(全新库);或已有 W19 库则跑 `deploy/w20_account_governance.sql` 升级。预检脚本 `deploy/w20_preflight_check.sql`。
4. 起服务:`cd server && npm run start`(或 dev);`cd admin && VITE_API_URL=http://127.0.0.1:3100/api npm run dev`(admin 在 5173,跨域打 3100,server 已开 cors)。
5. 插件:`npm run build:plugin` 生成 `plugin/content.js` → Chrome 加载已解压扩展 `plugin/` → 插件内 serverUrl 指向 `http://127.0.0.1:3100`。
6. 跑 §4 的 P0 真机验收(E2)→ E3 SQL 断言 → E4 收口 → 报 Chase 决定 merge/部署。
