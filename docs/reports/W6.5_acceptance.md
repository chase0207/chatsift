# W6.5 Acceptance — 会话合并 + completeness 累计

## 范围

- 修复采集侧 `conversation_id` 不稳定: 去掉头像 URL 和 URL 参数, 改为 `pageKey + nickname`。
- `nickname` 读不到或为 `unknown` 时跳过采集, 不上报 unknown 会话。
- 三个抖音 adapter 的 fallback 不再使用 `location.href`, 避免 query 波动。
- analyzer 中 intent 仍用最新 5 条 inbound, completeness 改用全量 inbound 历史。
- 清空测试业务数据后重跑 W3 四类工单验收。
- 真实抖音页面重采 `chase`, 验证只产生 1 条会话。

## 代码改动

- `plugin/runtime/legacy-collector.js`
  - `_buildSessionInfo()` seed 改为 `[pageKey, nickname]`
  - 读到空昵称或 `unknown` 返回 `null`
  - `collectMessageSession()` 遇到空 session info 跳过
- `plugin/adapters/douyin/private-message.adapter.js`
- `plugin/adapters/douyin/laike-message.adapter.js`
- `plugin/adapters/douyin/feige.adapter.js`
  - `toConversationEvent()` fallback 改为 `Dom.simpleHash(nickname)`
  - nickname 缺失或 `unknown` 时返回 `null`
- `server/src/v1/analyzer.js`
  - 新增 `completenessMessages`
  - completeness 查询全量 inbound, `LIMIT 500`
  - intent 继续使用原 `contextMessages` 最新 5 条
- `plugin/content.js`
  - 已重新 `npm run build:plugin` 生成

### 3. W3 四类工单验收

用 `/api/v1/events/batch` 上报 5 条事件:

- simple inquiry: `你好，在吗`
- appointment: `我想预约这周六陪驾，人在上海`
- appointment 续补: `电话13800138000，想去人民广场店`
- complaint: `我要投诉，你们老师太差了，要求退款`
- price inquiry: `上海陪驾10小时多少钱`

结果:

```text
conversation_id  intent_label    stage  completeness  message_count
1                simple_inquiry  new    0             1
2                appointment     done   100           2
3                complaint       done   0             1
4                price_inquiry   done   100           1
```

工单结果:

```text
inquiry      线索跟进:测试简单   completeness=0    priority=5
appointment 预约确认:测试预约   completeness=100  missing=[]
complaint   投诉处理:测试投诉   completeness=0    priority=1
pricing     报价回复:测试报价   completeness=100  suggestion=建议报价:1619.00元
```

结论:

- 四类意图分类正常。
- appointment 两条消息只生成 1 个 appointment 工单,去重正常。
- 报价单命中价格表,建议报价 1619 元。
- 投诉单 priority=1。

### 4. completeness 全量累计验证

用同一会话连续上报:

1. `姓名：刘思奇 / 电话：13913972023 / 上车位置：普陀区镇坪路魔方公寓 / 车型：轿车`
2. `我想预约这周六陪驾`
3. `好的`

结果:

```text
conversation_id  intent_label  stage       completeness  message_count
5                appointment   completing  80            3
```

工单:

```text
workorder_type=appointment
completeness_score=80
missing_fields=["store"]
payload={"city":"普陀","time":"这周六","store":null,"contact":"13913972023","project":"陪驾"}
```

结论:早期电话/位置字段没有被后续消息覆盖丢失,completeness 不再归 0。
